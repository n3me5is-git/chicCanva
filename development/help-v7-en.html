🧭 Finding your way around

chicCanva has a top project bar, a canvas toolbar, the active page, and a task-based sidebar.

How to use it

Use the sidebar shortcuts to open Page, Special, Text, Fonts, Emoji, Shapes, Images, Colorizer, Clipart, AI, or Export.

Practical example

Apply this feature to one page first, inspect the result at Fit and in Preview, then repeat it across the project when the layout is correct.

Keep in mind

The operation remains compatible with the project’s pages, undo history, autosave, and export unless this section explicitly describes a conversion or replacement.

  • Check the result on the canvas or in Preview before exporting.
  • Commands that create a copy preserve the source so you can compare or restore it.
  • Use Undo for unwanted canvas changes and keep a JSON backup for long-term editing.

🌐 Interface language

chicCanva includes Italian and English. On first launch it checks the complete browser locale list, choosing Italian when an Italian preference is present and English otherwise. Your later choice is remembered in browser storage. Newly generated project and page names follow the active UI language; existing names, prompts, fonts, and imported content remain unchanged.

How to use it

On desktop use the flag immediately before Guide; on mobile open the panel and use the selector above Storage. The language is applied before the interface and recovery dialog appear. Clearing app storage makes the next launch detect the browser language again.

❓ Frequently asked questions

Open a question for practical, non-technical guidance about normal app behavior.

Why does Colorizer fill outside an area?

The boundary may be open, too light, or close to the interior color. Undo, lower tolerance, close the gap with the smart brush, and fill again.

Can I edit text or shapes after Colorizer?

Yes. Restore original object recreates the editable source. Copy or duplicate the colorized image first if you want to keep both.

Why is Install missing?

Installation is shown only on a real HTTPS domain when the app is not already installed. It is intentionally hidden on file, localhost, IP, and private hosts.

Why does a font look different?

The catalogue is embedded, but the selected font file downloads on first use. If a network filter blocks it, the browser temporarily uses a fallback font.

Why can an image URL fail?

The link must return an image and permit cross-origin reading. Try Puter while signed in, or download/copy the image and upload/paste it.

Why do multiple PNG or JPG pages create a ZIP?

A ZIP keeps each page as a separate named file and is assembled entirely in the browser.

Why is PNG quality disabled?

PNG is lossless. Use DPI to control resolution; the quality slider applies to JPG compression.

Why can JPG not be transparent?

JPG has no alpha channel, so chicCanva applies a white background.

Will the grid be printed?

No. Grid lines, guides, selections, handles, and export rectangles are editor overlays only.

Does zoom change print quality?

No. Zoom changes only the working view. Page dimensions, source images, and export DPI determine output.

Why is rotation locked?

The rotation handle is opt-in to prevent accidental changes. Enable it only while rotating.

Where did the other sidebar sections go?

With Expand one at a time enabled, opening one section collapses the others. Disable it or choose Expand sections.

Can I change the font in text containing emoji?

Yes. Font changes reach text members of the mixed group. Ungroup to edit one member only.

Does local background removal upload my photo?

No. IMG.LY and ONNX download code and a model, then process pixels in the browser.

Why is the background model downloaded again?

The app, browser, or operating system may have cleared cached files to recover space.

Can I work offline?

Core editing and export work with embedded and cached resources. Puter and resources never downloaded before still require a connection.

What does project JSON save?

It saves editable state and embedded assets, plus history when that option is enabled.

Does autosave replace JSON backup?

No. Autosave protects one browser and origin; JSON is the portable archival copy.

How do I export one image?

Choose Current page or Selection on page. All pages creates a ZIP for raster formats.

How do I keep pages consistent?

Build one template page, duplicate it, and use grids, snapping, guides, and ordered names.

Why can AI post-processing take longer?

It is a second local segmentation process and may first need to load a model into memory.

Which files should I keep?

Keep JSON for future edits and PDF/PNG/JPG for printing or sharing.

Does imported PDF text remain editable?

No. Each imported PDF page becomes a PNG background; new chicCanva objects remain editable above it.
