# chicCanva AI-agent context

## Objective

chicCanva is a single-HTML, browser-based “mini Canva” for printable educational material. Chicca is the small teacher mascot; the current slogan is **“Piccole idee, grandi progetti.”** Preserve the one-HTML application, limited `file://` operation, richer HTTP(S) features, the dependency-free PowerShell launcher, and the deployable PWA bundle.
Italian is the editorial source and English is an equally complete runtime language. Every UI change must update the embedded language catalogue, the two selectors, and both guide generators. Never translate project content, names, filenames, user prompts, font names, or search results. AI style and chroma instructions follow the UI language and preserve the user prompt language for visible generated text. See docs/LOCALIZATION.md.

Do not edit generated `chicCanva.html`, build copies, `tests/v7-test.html`, or `docs/user-guide.html` as the primary source.

## Important current behaviors

- One custom-page model; “one letter/group per page” is a special macro.
- The special macro includes `constant` banner fitting: the largest group determines one common scale and every page centers content at that scale.
- Multiple projects stay open in tabs; imported JSON opens a new project.
- Every page has independent name, size, orientation, objects, and order.
- All sidebar cards start collapsed; single-section expansion is enabled by default.
- Text can be outline (transparent fill + configurable stroke) or filled.
- About 2,100 font metadata entries are embedded; font binaries load lazily.
- Smart emoji creates separate text/OpenMoji objects inside a separable group.
- OpenMoji has full browse/search/categories, color/black style, ink, and stroke width.
- Shapes are vector Fabric objects. Drawing mode disables target finding and interaction with existing objects until commit/cancel; polygonal objects expose editable anchors.
- Image operations preserve the original. Crop is non-destructive, previews excluded source areas translucently, and reset restores source geometry without changing its scale or proportions; other transforms create copies.
- Colorizer accepts any renderable object, group or multi-selection. Version 2 replaces the visible source with a `colorized` image while retaining source descriptors and an immutable `baseAssetId` in `asset.meta.colorizer`; the same metadata is serialized as `colorizerBackup` on the Fabric descriptor so undo/page changes can repair missing derived metadata. A PNG label mask identifies colored regions and `layers` stores their paint styles. Fill can restyle an existing region. Edge adhesion uses terminal contour-aware mask expansion plus paint-behind-alpha composition; do not replace it with unconstrained dilation because that can cross outlines. Brush/fill regions with identical styles merge only when they touch. The smart brush uses a connected-component mask from the gesture start, while unprotected brush strokes may cross outlines. The optimized brush batches pointer samples once per animation frame, replaces per-pixel `Set` allocation with reusable typed masks/index buffers, and renders a temporary DOM canvas overlay above Fabric. Pointer-up commits to the same canonical label map and compositor used by fill, so topology, antialias adhesion and reopen-after-scale behavior remain shared. The legacy path remains available with `?colorizerBrush=legacy` or the persistent `setChicCanvaColorizerBrushEngine('legacy')`; memory reset clears that override. Active and pending Colorizer assets must remain reachable during pruning. Each committed operation creates a derived PNG and serializes mask/layers for exact undo/redo; the work canvas, `ImageData`, label array and decoded images are released when the mode ends.
- Font/style changes inside persistent groups must rebuild the group bounds and restore its visual center. Test both mixed text/OpenMoji groups and groups made only from text; stale Fabric group bounds reproduce the left-clipping regression reported by the user.
- Pinch uses a temporary CSS transform only while two pointers are moving. At gesture end `layoutCanvasViewport` updates Fabric's backing raster using the dynamic retina scale and recalculates offsets and controls. Do not leave CSS-only zoom as the settled editor state because selections, crop, export regions and pointer mapping drift.
- PDF import is fully local: one/all source pages become PNG assets, each fitted without distortion onto an A4 portrait/landscape page. Destination can be a new project or append to the active one; quality is 1×–3×.
- Chroma-key automatic color detects the dominant perimeter color. Internal matching areas are removed by default.
- Every color input receives a canvas eyedropper. The picker samples the lower raster canvas using client-to-backing-buffer coordinates; do not replace it with Fabric document coordinates.
- IMG.LY background removal is local. Every run uses a disposable worker so ONNX sessions and tensors leave RAM at completion while model files remain in Cache Storage. Desktop keeps selectable models/devices; mobile forces `isnet_quint8` and downscales excessive input.
- Puter AI uses the curated profiles in `development/ai-generation.js`: GPT Image 2, GPT Image 2.5 Flare and Sunburst, Grok Imagine, Seedream 5 Lite, and Gemini 3.1 Flash Lite Image. Grok and the “Other” profiles are passed with their canonical namespaced Puter IDs and no forced provider fallback. Juggernaut Lightning, HiDream I1, and original Qwen Image are intentionally absent from the visible catalog because a 2026-09-11 live smoke test showed Puter rerouting those canonical IDs to an unavailable internal FLUX.1-schnell endpoint. The build strips the obsolete Together/Flux fallback and tests reject both its reintroduction and exposing those failing profiles. OpenAI supports a short-edge preset or exact width/height mode; both reject values outside multiples of 16, 1:3–3:1, 3840 px per edge, or 655,360–8,294,400 total pixels. Its GPT Image 2.5 output estimate uses OpenAI's public non-linear calculator formula. Text input remains a character/token heuristic; reference-image input uses a labelled Vision-derived proxy because OpenAI explicitly excludes GPT Image generation/editing from its Vision calculator. Gemini Flash Lite exposes its discrete ratios and 1K only; Grok exposes 1K/2K but Puter's `txt2img` adapter does not document ratio forwarding. Remote generated URLs are recovered in order from an origin-clean returned image, direct fetch, the bounded localhost proxy, and `puter.net.fetch()`. If every conversion path fails, the generated result remains visible in a persistent preview with retry, download, open, and fullscreen actions instead of being discarded. `puter-billing.js` computes global use as monthly allowance use plus consumed purchase credits and global remaining as the two residual buckets; the bar therefore includes top-ups and documents allowance-first deduction. Image pricing uses a recognized-field-only 30-day local cache with stale-if-error and embedded fallback. Prompt Library supports text/image clipboard copy, prioritizes its Use action, and the AI prompt has append-from-clipboard plus a raw effective-prompt preview. AI controls stay hidden until explicit Puter sign-in; the account bar supports account switching and logout. Generation always requires an explicit click.
- Canvas navigation supports Fit, numeric zoom, Ctrl+wheel, hand pan, and a two-touch pinch that zooms around the gesture midpoint while panning. Narrow touch viewports use larger visible Fabric controls plus a 40–44 px invisible hit area for selections, crop edges, and editable shape vertices; desktop pointer controls retain their original metrics.
- Clipart searches public Openclipart pages and expects English keywords. Translation first resolves known terms through a compact internal didactic dictionary, then a persistent browser cache, and finally `google/gemma-4-31b-it` through Puter's OpenRouter provider when signed in. The preferred call uses `reasoning: {effort: 'low'}`; failure or an invalid response triggers one retry through Puter's default route without reasoning parameters. The defensive parser removes thought tags. The cache retains at most 500 successful AI translations and the app memory reset clears it. Emoji uses the same policy; with translation active it searches only on Enter or the explicit magnifier and keeps a busy state from translation through result rendering. Openclipart parsing stops after 12 unique results per remote page and thumbnails use native lazy loading, reducing preview requests without removing previous/next navigation.
- Autosave uses IndexedDB generation records referenced by small stable `workspace-current`/`workspace-previous` pointers, an immediate dirty marker, a 1.2 s debounce, and a small synchronous fallback. Rotation does not read the previous large JSON into RAM. A serialized workspace stores the active project once and project switches do not deep-clone asset Data URL strings. Startup can recover without a localStorage pointer and legacy records remain readable.
- Asset GC runs after history truncation, redo-branch replacement, page deletion, object deletion, and explicit project close. Preserve references reachable from current pages/history plus the independent last AI reference and internal clipboard. Only the active page is instantiated in Fabric; page changes explicitly clear decoded image elements and object/filter cache canvases from retired objects while retaining encoded assets and descriptors.
- Undo/redo entries contain page collections and minimal page cursor/mode metadata only. Tool settings, drafts, prompts, searches, AI references, zoom/pan, sidebar/preview/export choices and other non-canvas preferences stay in autosave but must not create history entries or be rolled back. A control change is historical only when it changes a page or object.
- The image widget reports source/crop pixels, encoded bytes, decoded bitmap RAM estimate, physical size, and effective DPI. It copies either the untouched source or the active crop at native crop resolution. Local resampling can replace one selected image at ¼×, ⅓×, ½×, 2×, 3×, or 4× without changing its page geometry or crop; reductions use progressive high-quality passes.
- Object position lock is context-menu-only and serialized. Touch users open the same menu with a stationary 1.4 s long press. Export-region mode temporarily disables target finding and restores each object's previous interaction flags on exit.
- Export supports PDF, PNG, JPG, region, and client-side ZIP. JSON can optionally include history.
- PWA is offered only on public HTTPS domains, not file/localhost/IP/private hosts. The Install command opens the app dialog; the bottom **Install with browser** button is always present; when `beforeinstallprompt` is available it triggers the native browser prompt, otherwise the dialog gives platform-specific steps. Updates use a waiting-worker banner and explicit activation. Its lightweight `index.html` exposes static title, description and absolute Open Graph/Twitter URLs from `CHICCANVA_PUBLIC_URL` (default `https://chiccanva.testthis.one/`) plus a versioned 1200×630 JPEG card with the centered Chicca logo. On Coolify/Traefik the domain must be configured as **Indexable** so the proxy does not inject a generic noindex header. The project sends targeted Googlebot/Bingbot noindex metadata, explicitly allows Telegram, WhatsApp, Facebook, X/Twitter, LinkedIn, Slack and Discord preview crawlers in `robots.txt`, and disallows the generic crawler group.

## Non-negotiable implementation rules

1. Preserve the single application HTML and PowerShell-only launcher.
2. Keep existing functions unless the user explicitly replaces them.
3. Core editing must remain useful from `file://`; HTTP-only widgets are disabled with the exact user-oriented message.
4. Do not silently use Puter or another user-pays service.
5. Preserve image originals and editable project state.
6. Keep mobile memory safeguards.
7. Maintain stable DOM IDs and module injection order.
8. Update guide, README, docs, context, generated builds, and tests with material changes.
9. Do not delete or modify `.codex-remote-attachments/` or historical `old/` files unless explicitly requested.
10. Respect third-party licenses: original chicCanva code is MIT; PDF.js is Apache-2.0; embedded IMG.LY is AGPL-3.0; OpenMoji graphics are CC BY-SA 4.0; Openclipart works are declared public domain/CC0; Fabric/jsPDF/ONNX Runtime are MIT; fonts retain individual licenses.
11. Keep `development/version.json`, the generated build date, the in-app footer, documentation, root HTML, local build, and PWA build synchronized through `build-workspace.py`.

## Known architectural risks

- The application composer performs asserted string replacements on a large baseline; changed anchors fail the build.
- Feature modules wrap global functions, so injection order and exactly-once predecessor calls matter.
- One syntax error breaks the whole single HTML; Node inline syntax validation and browser tests are mandatory.
- Large Data URL assets/history can pressure browser storage and memory.
- PWA/CDN service-worker caching can present stale builds if the SW response is cached upstream.
- External services may be blocked by CORS, ad blockers, network policy, rate limits, or account state.
- Distributing/hosting the combined build requires attention to IMG.LY AGPL obligations and OpenMoji attribution/share-alike terms.

- GPT Image 2.5 Flare and Sunburst can send one clean reference plus one temporary annotated copy. Persist only normalized marker geometry/comments; point markers store a center, while rectangles and ovals store bounds. The localized technical append uses `user_comment: {…}`, appears unchanged in the raw-prompt preview, and doubles only the reference-input portion of the estimate. The annotation editor caps its decoded working preview at a 2048 px long edge, releases that bitmap/canvas when closed, and keeps its comment panel as a transform-only overlay so it cannot resize the main workspace. The panel handle protrudes above the closed panel, so never apply paint containment to that panel. Its gray workspace contains a white image stage; the optional black transparency-preview background is session-only CSS, enabled only after alpha detection, and never enters saved state or submitted pixels. The modal temporarily hosts the shared localized tooltip inside the browser top layer and restores it on close.

- Sidebar divider movement preserves its starting zoom mode, uses a coalesced CSS-transform canvas preview, and performs the full Fabric raster update only on release. Opening and closing the sidebar also preserves Fit or the selected explicit zoom on desktop and mobile. The toolbar retains its native horizontal scrollbar with extra lower clearance and also maps an ordinary vertical wheel gesture to horizontal scrolling while hovered.

- Puter fetch checkboxes remain disabled and unchecked until the AI section reports an active Puter session. Login links navigate to that section; they must never open nested dialogs.

- Pinch uses CSS-only canvas sizing per animation frame and performs one Fabric raster refresh on gesture end. Non-fit zoom provides viewport-relative overscroll space for unrestricted hand panning.

- Shapes are categorized and paginated. Point editing persists until explicitly stopped; polygon/polyline nodes support click mode on desktop and drag-segment mode by default on touch. Smooth freehand uses weighted filtering plus Ramer-Douglas-Peucker simplification.
- Snap also quantizes rotation with a project-persisted 10° default. Rotation/flip menus are available from the toolbar and object context menu. Selection-by-object provides cumulative touch selection, and any renderable selection can be duplicated as a raster image.
- Copy is multipurpose and unified across toolbar, context menu and keyboard: it stores editable descriptors internally and attempts an external PNG of the same selection. Standard paste always prefers the internal structured payload; OS clipboard images are only a Ctrl/Cmd+V fallback when no internal copy exists. Direct single-text editing supports fixed width, height, both or natural size with a stable top-left anchor.
- Alignment guides and classic snap apply during movement, resize and non-destructive crop. Page-center and all four page-edge guides are independently configurable. The object context menu offers fitting with the configurable millimetre margin or with zero margin. Aspect locking restores the opposite Fabric control anchor; Shift inverts it for the gesture. Escape restores the start pose of an active transform or cancels crop/shape drawing. Canvas long press is 1.25 s, aligned closely with the 1.2 s toolbar menus.
- Puter's live `allowanceInfo.remaining` is authoritative for the global remaining bar. Allowance and top-up totals, used values and residual values are rendered separately. The local list-price estimate uses OpenAI's public GPT Image 2.5 output-token formula and labels its text/reference-input proxies, while an app-scoped before/after usage delta is cached as `Ultima Gen` for each generation profile.
- The interaction additions live in `development/interaction-ui.html`, `interaction-upgrades.css`, and `interaction-upgrades.js`; keep their build order after `shapes.js`.
